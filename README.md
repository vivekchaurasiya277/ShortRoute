# ShortRoute 🌍🚀

**ShortRoute is a next-generation travel routing application designed to seamlessly calculate the most efficient, cheapest, and fastest journeys across cities and states. Built with an immersive 3D-parallax interface, it dynamically combines various modes of transport—walking, autos, metro, buses, trains, and cabs—into single, cohesive itineraries.**

**Powered by a hybrid routing engine, ShortRoute utilizes a massive offline dataset of 700 districts for instantaneous calculations, while seamlessly falling back to live GPS and OpenStreetMap (OSRM) data for custom locations nationwide.**

**Key features include triple-tier itinerary sorting (Fastest, Cheapest, Balanced), multi-language support, native dark mode, and a dynamic UI featuring animated SVG energy lines over a topographic 3D background. Instead of clunky web views, ShortRoute honors user preference by deep-linking directly into native booking apps like Uber, Ola, and RedBus, automatically injecting search parameters for a frictionless, end-to-end travel experience.**

---

### 🚀 Quick Start

**1. Start Backend API**
```bash
cd apps/api
npm install && npm run dev
```

**2. Start Frontend App**
```bash
cd apps/mobile
npm install && npx expo start --web
```

*Built with React Native, Node.js, and Expo.*
